# برنامه کار فیلم‌بردار — Android Studio

این پروژه نسخه اندرویدی برنامه تقویم و مدیریت پروژه فیلم‌برداری است.

## امکانات
- تقویم شمسی روزانه/هفتگی/ماهانه
- ثبت پروژه، مشتری، مکان، زمان و یادداشت
- ثبت تعداد سناریو برای هر پروژه
- قیمت پروژه به ریال
- گزارش ماهانه: تعداد پروژه، سناریو و درآمد
- خروجی گزارش ماهانه Excel با ذخیره مستقیم در پوشه Download اندروید
- ذخیره اطلاعات در localStorage خود WebView
- پشتیبان‌گیری و بازیابی داخل خود برنامه
- حالت روشن/تیره سیستم

## ساخت APK
1. این پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را بزنید.
4. APK ساخته‌شده در `app/build/outputs/apk/debug/` قرار می‌گیرد.

پروژه برای Android Studio جدید با Android Gradle Plugin 8.7.3 و compileSdk 35 تنظیم شده است.
# ساخت APK بدون Android Studio

این پروژه برای ساخت APK روی GitHub Actions آماده شده است. نیازی به نصب Android Studio، Android SDK یا Gradle روی کامپیوتر شما نیست؛ GitHub روی سرور خودش محیط Build را اجرا می‌کند.

## مراحل

1. وارد GitHub شوید و یک حساب بسازید یا وارد حساب فعلی شوید.
2. یک Repository جدید بسازید، مثلاً `film-schedule`.
3. تمام فایل‌های داخل این پوشه را در Repository آپلود کنید (خود پوشه `FilmScheduleAndroid` را به‌عنوان ریشه Repository آپلود کنید، نه یک پوشه تو در تو).
4. بعد از Push شدن فایل‌ها، از تب **Actions** وارد workflow با نام **Build Android APK** شوید.
5. روی **Run workflow** بزنید. اگر workflow با Push خودکار اجرا شده، همان اجرای موجود را باز کنید.
6. وقتی کار سبز و `Success` شد، پایین صفحه بخش **Artifacts** را باز کنید.
7. فایل `FilmSchedule-debug-apk.zip` را دانلود و Extract کنید. داخل آن `app-debug.apk` قرار دارد.
8. فایل APK را به گوشی منتقل و نصب کنید.

## نکته

این خروجی Debug APK است و برای نصب و تست روی گوشی مناسب است. برای انتشار در Google Play یا توزیع رسمی، بعداً باید یک Release APK/AAB با کلید امضای شخصی ساخته شود.
